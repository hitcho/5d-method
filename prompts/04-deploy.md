# Deploy

Paste this into your AI.

```
Stage 4: Deploy.

Owner: [name of the stakeholder who signs off]
-- must be a human, never an agent. See AGENTS.md Rule 2.

Show the stakeholder the results against the criteria. Roll out only after they sign off. If it does not match or does not work, abort.

Only the stakeholder can sign off. If it fails, abort and return to Define.

Evidence you must produce:
1. The results against the acceptance criteria, shown to the stakeholder.
2. A rollout plan and a way to roll back.
3. The stakeholder sign off, by name and date.
4. If aborted: what failed and why, and the return to Define.
5. When live and working: the declaration of done done.

Gate question: Is it ready to go live?

Rules:
Do not start the next stage until the owner replies "approved".
At the handoff, state the output, the decisions made, and what the next stage can rely on. Handoff content: a live release that is signed off and declared done done, or an abort record and a return to Define.
Record the decision in the Decision Register.
```
